# 1-外壳-栏收起按钮

| 项 | 值 |
|---|---|
| ID / data-testid | `shell.collapse-button` |
| 类型 | 按钮 |
| 级数 | 1 |
| 上级规格 | —（复用组件，见“上一级”） |
| 概念图 | [UI-05](../../../assets/ui/05-workspace-branch.png) |
| 建议组件 | `web/src/layout/CollapseButton.tsx` |
| 里程碑 | F1（外壳、项目栏、文件栏） |
| 规格状态 | 草案 v0.1，2026-11-22，待用户确认 |

项目栏、文件栏、右栏右上角的面板图标（用户指定图标：圆角面板 + 竖分隔线 + 左侧两条短线；右栏用镜像版）。点击收起所在栏。

## 上一级：从哪里进来

| 入口 | 触发条件 | 传入的数据 / 接口 |
|---|---|---|
| 项目栏头部 | 渲染 | props `index: 0` |
| 文件栏头部 | 渲染 | props `index: 1` |
| 右栏标签条右端 | 渲染 | props `index: 3` |

其他指向本规格的规格：[1-外壳-项目栏](../01-项目栏/1-外壳-项目栏.md)、[1-外壳-文件栏](../02-文件栏/1-外壳-文件栏.md)、[1-右栏-标签条](../06-右栏/1-右栏-标签条.md)。

## 下一级：去哪里

| 操作 | 结果 | 目标规格 | 调用的接口 / store action |
|---|---|---|---|
| 点击 | 该栏收起为竖条 | [1-外壳-收起态竖条](1-外壳-收起态竖条.md) | `useLayout.toggle(index)` |

## 接口

不直接调用后端接口。

## 读写的前端状态

- useLayout.toggle

## 状态

| 状态 | 表现 |
|---|---|
| 默认 | 28×28 图标按钮，`--muted` 色 |
| 悬停 | `--sel` 底色，`--ink` 色 |
| 聚焦 | 2 px 焦点环 |

## 交互细则

- 图标使用 `web/src/icons/panelL.svg` 与 `panelR.svg`（从概念图 components.js 的 panelL/panelR 路径重画，不拷代码）。
- aria-label：“收起项目栏 / 收起文件栏 / 收起右栏”。

## 验收

- [ ] 三处按钮都能收起对应栏，刷新后保持。
- [ ] 所有可点元素带 `data-testid`，键盘可达，焦点可见。
