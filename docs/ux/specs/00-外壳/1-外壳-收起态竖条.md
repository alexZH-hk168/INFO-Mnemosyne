# 1-外壳-收起态竖条

| 项 | 值 |
|---|---|
| ID / data-testid | `shell.collapsed-rail` |
| 类型 | 模块 |
| 级数 | 1 |
| 上级规格 | —（复用组件，见“上一级”） |
| 概念图 | 无（实现前需补概念图或实现后截图确认） |
| 建议组件 | `web/src/layout/CollapsedRail.tsx` |
| 里程碑 | F1（外壳、项目栏、文件栏） |
| 规格状态 | 草案 v0.1，2026-11-22，待用户确认 |

栏收起后的 44 px 竖条：顶部是展开按钮，下方竖排栏名（“项目”“文件”“预览”），右栏竖条另显示已打开标签数。

## 上一级：从哪里进来

| 入口 | 触发条件 | 传入的数据 / 接口 |
|---|---|---|
| 应用外壳 | `useLayout.collapsed[i] === true` 时替代该栏 | props `index` |

其他指向本规格的规格：[1-外壳-栏收起按钮](1-外壳-栏收起按钮.md)。

## 下一级：去哪里

| 操作 | 结果 | 目标规格 | 调用的接口 / store action |
|---|---|---|---|
| 点击展开按钮或竖条空白处 | 展开该栏，宽度恢复收起前的值 | — | `useLayout.toggle(index)` |

## 接口

不直接调用后端接口。

## 读写的前端状态

- useLayout.collapsed
- useLayout.rightTabs.length（右栏）

## 状态

| 状态 | 表现 |
|---|---|
| 默认 | `--faint` 色竖排文字，letter-spacing .2em |
| 右栏有新标签打开 | 右栏竖条自动展开，不停留在收起态 |

## 交互细则

- 概念图未画收起态，样式按 common.css 的 `.rail` 实现。
