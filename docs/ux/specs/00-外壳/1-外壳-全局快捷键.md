## 下一级：去哪里

| 操作 | 结果 | 目标规格 | 调用的接口 / store action |
|---|---|---|---|
| Alt+1 / Option+1 | 切换项目栏 | — | `useLayout.toggle(0)` |
| Alt+2 / Option+2 | 切换文件栏 | — | `useLayout.toggle(1)` |
| ⌘. / Ctrl+. | 切换右栏 | — | `useLayout.toggle(3)` |
| ⌘K / Ctrl+K | 新建对话 | [1-项目栏-新建对话按钮](../01-项目栏/1-项目栏-新建对话按钮.md) | 同新建对话按钮 |
| Esc | 依次关闭：弹层 → 弹窗 → 划词工具条 | — | `useUI.popover=null` / `useUI.modal=null` / `useUI.selection=null` |

不直接调用后端接口。

- useUI

## 状态

| 状态 | 表现 |
|---|---|
| 输入框聚焦时 | Alt+1 / Alt+2 / ⌘. 仍生效，且不往输入框插入字符；Esc 先交给输入框的弹层 |

## 交互细则

- 在 `<input>`、`<textarea>` 内不拦截普通字符键。
- Alt+1 / Alt+2 只按 `event.code`（`Digit1` / `Digit2`）判断：Mac 的 Option+数字会产生“¡”“™”等字符，`event.key` 不可靠；同时按住 ⌘/Ctrl 时不响应（Windows 的 AltGr 即 Ctrl+Alt）。
- 不用 ⌘/Ctrl+1/2：在浏览器里是切换标签页，页面拦不到（编排决定 U20，待用户追认）。
