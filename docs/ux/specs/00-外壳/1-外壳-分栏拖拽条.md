# 1-外壳-分栏拖拽条

| 项 | 值 |
|---|---|
| ID / data-testid | `shell.resize-handle` |
| 类型 | 按钮 |
| 级数 | 1 |
| 上级规格 | [1-启动-应用外壳](1-启动-应用外壳.md) |
| 概念图 | [UI-05](../../../assets/ui/05-workspace-branch.png) |
| 建议组件 | `web/src/layout/ResizeHandle.tsx` |
| 里程碑 | F1（外壳、项目栏、文件栏） |
| 规格状态 | 草案 v0.1，2026-11-22，待用户确认 |

相邻两栏之间 8 px 宽的拖拽区。悬停出现 2 px 竖线，拖动实时改两侧宽度。

## 上一级：从哪里进来

| 入口 | 触发条件 | 传入的数据 / 接口 |
|---|---|---|
| 应用外壳 | 渲染 3 个 | props `index: 0\|1\|2`（左侧栏序号） |

## 下一级：去哪里

| 操作 | 结果 | 目标规格 | 调用的接口 / store action |
|---|---|---|---|
| 拖动 | 实时调整左侧栏宽度，右侧弹性栏吸收差值 | — | `useLayout.setSize(index, px)` |
| 双击 | 恢复左侧栏默认宽度 | — | `useLayout.resetSize(index)` |
| 键盘 ← / →（获得焦点时） | 每次 ±16 px | — | `useLayout.setSize` |

## 接口

不直接调用后端接口。

## 读写的前端状态

- useLayout.sizes
- useLayout.setSize / resetSize

## 状态

| 状态 | 表现 |
|---|---|
| 默认 | 透明，光标普通 |
| 悬停 | 中间 2 px 竖线 `#9d998f`，光标 `col-resize` |
| 拖动中 | 竖线保持，`body` 加 `user-select:none` |
| 一侧已收起 | 不渲染（收起的竖条自带边界） |

## 交互细则

- 到最小或最大宽度后不再变化，不弹提示。
- role="separator"，`aria-orientation="vertical"`，`aria-valuenow` 为当前宽度。

## 验收

- [ ] 拖动 60 fps 无抖动；松手后宽度写入 localStorage。
- [ ] 双击恢复默认值。
- [ ] 无法拖出 state.md 规定的最小/最大宽度。
- [ ] 所有可点元素带 `data-testid`，键盘可达，焦点可见。
