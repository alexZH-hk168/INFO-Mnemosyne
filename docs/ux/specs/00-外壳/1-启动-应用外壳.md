## 接口

| 类型 | 名称 | 何时调用 | 字段与说明 |
|---|---|---|---|
| query | `['projects']` | 启动时 | 决定默认项目：URL 无项目时取最近更新的项目；没有项目时创建“默认项目” |
| REST | `POST /api/projects` | 首次启动且项目列表为空 | `{name:"默认项目"}` |

字段定义见 [REST](../../../contract/rest-api.md)、[SSE](../../../contract/sse-events.md)、[类型](../../../contract/types.ts)；query key 见 [state.md](../../../ux/state.md)。

## 读写的前端状态

- useLayout（全部）
- useChat.projectId / conversationId / activeBranchId

## 状态

| 状态 | 表现 |
|---|---|
| 首次加载 | 四栏骨架屏，项目栏与文件栏显示 3 行灰条 |
| 后端不可达 | 顶部全局提示“无法连接后端”（shell.toast），各栏保留骨架 |
| 窗口宽 < 1100 px | 文件栏自动收起；< 900 px 项目栏也收起（只改运行时状态，不写 localStorage） |

## 交互细则

- 外层容器 `padding: 8px`，每栏是圆角 14 px 的浮起面板（`--panel` 底、`--line` 边）。
- 对话栏不可收起；其余三栏收起后变成 44 px 竖条（shell.collapsed-rail）。
- 路由变化只改 store，不重新挂载四栏，保证拖拽宽度不跳。
