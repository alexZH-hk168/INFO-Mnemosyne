# 1-外壳-全局提示

| 项 | 值 |
|---|---|
| ID / data-testid | `shell.toast` |
| 类型 | 模块 |
| 级数 | 1 |
| 上级规格 | [1-启动-应用外壳](1-启动-应用外壳.md) |
| 概念图 | 无（实现前需补概念图或实现后截图确认） |
| 建议组件 | `web/src/layout/Toasts.tsx` |
| 里程碑 | F1（外壳、项目栏、文件栏） |
| 规格状态 | 草案 v0.1，2026-11-22，待用户确认 |

右下角的提示队列与顶部的连接状态条。

## 上一级：从哪里进来

| 入口 | 触发条件 | 传入的数据 / 接口 |
|---|---|---|
| 任意组件 | `useUI.pushToast({kind, text, action?})` | `kind: info\|success\|error` |
| SSE 客户端 | 重连中 / 重连失败 | `useUI.pushToast` |

其他指向本规格的规格：[1-对话栏-流式连接](../05-对话栏/1-对话栏-流式连接.md)、[2-划词工具条-复制](../05-对话栏/2-划词工具条-复制.md)。

## 下一级：去哪里

| 操作 | 结果 | 目标规格 | 调用的接口 / store action |
|---|---|---|---|
| 提示上的操作按钮（如“重试”“查看日志”） | 执行调用方传入的回调 | — | `action.onClick` |

## 接口

不直接调用后端接口。

## 读写的前端状态

- useUI.toasts

## 状态

| 状态 | 表现 |
|---|---|
| info/success | 4 s 后自动消失 |
| error | 不自动消失，带关闭按钮 |
| 同时 > 3 条 | 只显示最新 3 条 |

## 交互细则

- 不用浏览器 alert。

## 验收

- [ ] 错误提示可键盘关闭；屏幕阅读器以 `role=status`（info）/`role=alert`（error）播报。
- [ ] 所有可点元素带 `data-testid`，键盘可达，焦点可见。
