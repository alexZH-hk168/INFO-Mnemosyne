# 1-输入框-引用范围

| 项 | 值 |
|---|---|
| ID / data-testid | `composer.scope` |
| 类型 | 按钮 |
| 级数 | 1 |
| 上级规格 | [1-外壳-输入框](1-外壳-输入框.md) |
| 概念图 | 无（实现前需补概念图或实现后截图确认） |
| 建议组件 | `web/src/chat/ScopePicker.tsx` |
| 里程碑 | F3（对话流、输入框、证据胶囊） |
| 规格状态 | 草案 v0.1，2026-11-22，待用户确认 |

托条上的“引用范围”胶囊，显示“全部材料 / 已选 N 个文件 / 不用材料”，点击弹出三选一菜单。

## 上一级：从哪里进来

| 入口 | 触发条件 | 传入的数据 / 接口 |
|---|---|---|
| 输入框托条 | 渲染 | 读 `useChat.composer.scope` |

## 下一级：去哪里

| 操作 | 结果 | 目标规格 | 调用的接口 / store action |
|---|---|---|---|
| 选择“全部材料” | — | — | `scope={mode:"all"}` |
| 选择“只用已选文件” | 打开 @ 引用列表 | [2-艾特-文件引用列表](2-艾特-文件引用列表.md) | `scope.mode="selected"` |
| 选择“不用材料” | — | — | `scope={mode:"none"}` |

## 接口

不直接调用后端接口。

## 读写的前端状态

- useChat.composer.scope
- useUI.popover="scope"

## 状态

| 状态 | 表现 |
|---|---|
| mode=all | “全部材料” |
| mode=selected | “已选 2 个文件”，悬停列出文件名 |
| 项目无材料 | 胶囊置灰，固定 none |

## 验收

- [ ] 选择后发送请求体中的 scope 与显示一致。
- [ ] 所有可点元素带 `data-testid`，键盘可达，焦点可见。
