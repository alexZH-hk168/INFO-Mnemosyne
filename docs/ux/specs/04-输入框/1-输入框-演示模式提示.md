# 1-输入框-演示模式提示

| 项 | 值 |
|---|---|
| ID / data-testid | `composer.demo-notice` |
| 类型 | 模块 |
| 级数 | 1 |
| 上级规格 | [1-外壳-输入框](1-外壳-输入框.md) |
| 概念图 | 无（实现前需补概念图或实现后截图确认） |
| 建议组件 | `web/src/chat/DemoModeNotice.tsx` |
| 里程碑 | BYOK（用户自带模型密钥（v0.5）） |
| 规格状态 | 草案 v0.1，2026-11-22，待用户确认 |

未配置模型时，输入框下沿一行轻量提示：“演示模式：未配置模型，回答由本地示例生成 去设置”。不假装是真实回答。

## 上一级：从哪里进来

| 入口 | 触发条件 | 传入的数据 / 接口 |
|---|---|---|
| 输入框（主页 / 对话 / 分支三种变体中的主页与对话） | 渲染在输入框卡片下沿 | 读 `['settings'].llm_mode` |

## 下一级：去哪里

| 操作 | 结果 | 目标规格 | 调用的接口 / store action |
|---|---|---|---|
| 去设置 | 打开设置弹窗的模型页 | [3-设置-模型](../08-设置/3-设置-模型.md) | `useUI.openModal("settings", {section:"model"})` |

## 接口

不直接调用后端接口。

## 读写的前端状态

- useUI.modal

## 状态

| 状态 | 表现 |
|---|---|
| llm_mode=real | 不渲染 |
| llm_mode=demo | 小圆点 + “演示模式：未配置模型，回答由本地示例生成” + “去设置” |
| llm_mode=demo_forced | “演示模式：服务端只用本地示例回答（测试用）”，不带“去设置” |
| 设置未加载完 | 不渲染，避免闪烁 |

## 交互细则

- 12 px、`--muted` 色，一行，不用红色、不弹窗、不挡输入。
- 只放这一处，不在每条回答上重复标注。

## 验收

- [ ] 未配置时主页与对话栏输入框下都能看到提示；点“去设置”打开模型页。
- [ ] 保存真实模型配置后提示消失。
- [ ] 所有可点元素带 `data-testid`，键盘可达，焦点可见。
