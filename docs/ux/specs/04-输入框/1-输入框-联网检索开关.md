# 1-输入框-联网检索开关

| 项 | 值 |
|---|---|
| ID / data-testid | `composer.web-toggle` |
| 类型 | 按钮 |
| 级数 | 1 |
| 上级规格 | [1-外壳-输入框](1-外壳-输入框.md) |
| 概念图 | [UI-11](../../../assets/ui/11-plugin-popover.png) |
| 建议组件 | `web/src/chat/ComposerBar.tsx` |
| 里程碑 | F3（对话流、输入框、证据胶囊） |
| 规格状态 | 草案 v0.1，2026-11-22，待用户确认 |

托条左侧“联网检索”胶囊开关。开启后本轮允许模型调用 `search_web` / `fetch_url`。

## 上一级：从哪里进来

| 入口 | 触发条件 | 传入的数据 / 接口 |
|---|---|---|
| 输入框托条 | 渲染 | 初值取 `settings.web_search_default` |

## 下一级：去哪里

| 操作 | 结果 | 目标规格 | 调用的接口 / store action |
|---|---|---|---|
| 点击 | 切换 `composer.web_search` | — | 随发送写入 `SendMessageBody.web_search` |

## 接口

不直接调用后端接口。

## 读写的前端状态

- useChat.composer.web_search

## 状态

| 状态 | 表现 |
|---|---|
| 开 | 实心胶囊，地球图标 `--ink` |
| 关 | 幽灵胶囊 `--muted` |

## 验收

- [ ] 关闭时发送的请求体 `web_search=false`。
- [ ] 所有可点元素带 `data-testid`，键盘可达，焦点可见。
