# 1-新建对话-主页

| 项 | 值 |
|---|---|
| ID / data-testid | `home.onboard` |
| 类型 | 窗口 |
| 级数 | 1 |
| 上级规格 | [1-启动-应用外壳](../00-外壳/1-启动-应用外壳.md) |
| 概念图 | [UI-01](../../../assets/ui/01-home.png) |
| 建议组件 | `web/src/home/Onboard.tsx` |
| 里程碑 | F2（主页与卡片） |
| 规格状态 | 草案 v0.1，2026-11-22，待用户确认 |

没有打开对话时中间区显示的主页：宋体大标题“今天要学习什么？”、双层输入框、扇形叠放的三张能力卡片。主页不显示“长期记忆已开启”之类的记忆提示。

| 首次进入 / 新建对话按钮 / ⌘K / 切到另一个项目 | `useLayout.view === "home"` | 读 `useChat.projectId` |

其他指向本规格的规格：[1-项目栏-新建对话按钮](../01-项目栏/1-项目栏-新建对话按钮.md)、[2-新建项目-新建项目弹窗](../01-项目栏/2-新建项目-新建项目弹窗.md)、[2-卡片介绍弹窗-知道了按钮](2-卡片介绍弹窗-知道了按钮.md)。

## 接口

不直接调用后端接口。

## 读写的前端状态

- useLayout.view
- useChat.projectId

## 状态

| 状态 | 表现 |
|---|---|
| 默认 | 标题、输入框、卡片垂直居中偏上（与 UI-01 对齐） |
| 窗口高度 < 760 | 卡片缩小到 0.85 倍，仍不与输入框重叠 |

## 交互细则

- 标题字体 `--serif`；颜色 `--ink`。
- 主页本身不发请求。

## 验收

- [ ] 与 UI-01 截图对齐；输入框自动获得焦点。
- [ ] 所有可点元素带 `data-testid`，键盘可达，焦点可见。
