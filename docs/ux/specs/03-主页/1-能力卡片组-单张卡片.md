# 1-能力卡片组-单张卡片

| 项 | 值 |
|---|---|
| ID / data-testid | `home.card` |
| 类型 | 按钮 |
| 级数 | 1 |
| 上级规格 | [1-主页-能力卡片组](1-主页-能力卡片组.md) |
| 概念图 | [UI-01](../../../assets/ui/01-home.png) |
| 建议组件 | `web/src/home/Card.tsx` |
| 里程碑 | F2（主页与卡片） |
| 规格状态 | 草案 v0.1，2026-11-22，待用户确认 |

一张能力卡：封面插画（论文页高亮 / 代码逐行高亮 / 课件计算图）＋标题。封面内部有循环小动画。

## 上一级：从哪里进来

| 入口 | 触发条件 | 传入的数据 / 接口 |
|---|---|---|
| 能力卡片组 | 渲染 3 张 | props `card`, `index`, `hovered` |

## 下一级：去哪里

| 操作 | 结果 | 目标规格 | 调用的接口 / store action |
|---|---|---|---|
| 点击 / Enter | 从卡片原位放大成介绍弹窗（共享元素过渡），背后主页毛玻璃 | [2-能力卡片-卡片介绍弹窗](2-能力卡片-卡片介绍弹窗.md) | `useUI.openModal("card-intro", {card})` |

## 接口

不直接调用后端接口。

## 读写的前端状态

- useUI.modal

## 状态

| 状态 | 表现 |
|---|---|
| 封面动画 | 论文：高亮条从左向右扫过；代码：逐行高亮；课件：梯度箭头反向流动。周期 4–6 s |
| 减少动效 | 静态封面 |

## 交互细则

- 封面组件 `covers/PaperCover.tsx`、`CodeCover.tsx`、`SlideCover.tsx`，用 SVG/HTML 重画，不拷概念图代码。
- 卡片是 `<button>`，aria-label“了解论文阅读”等。

## 验收

- [ ] 三张卡点击都能打开对应介绍弹窗。
- [ ] 所有可点元素带 `data-testid`，键盘可达，焦点可见。
