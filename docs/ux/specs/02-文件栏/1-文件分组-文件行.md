## 读写的前端状态

- useLayout.rightTabs

## 状态

| 状态 | 表现 |
|---|---|
| queued/parsing | 右侧“解析 62%”，文字 `--muted`，不可点击预览 |
| ready | 右侧页数/行数 |
| failed | 文件名旁红点，悬停显示 `parse_error`，右侧“重试” |
| 当前预览中 | 白底描边（UI-05 选中样式） |

## 交互细则

- 类型色：pdf `#c9584a`、pptx `#d0793d`、code `#4b6f9e`、ipynb `#e08a2c`、md `#7d7a73`。
- 解析完成前不进入检索，回答不会引用它（后端保证）。
