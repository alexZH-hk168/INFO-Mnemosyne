# 1-项目栏-项目行

| 项 | 值 |
|---|---|
| ID / data-testid | `sidebar.project-row` |
| 类型 | 按钮 |
| 级数 | 1 |
| 上级规格 | [1-外壳-项目栏](1-外壳-项目栏.md) |
| 概念图 | [UI-05](../../../assets/ui/05-workspace-branch.png) |
| 建议组件 | `web/src/project/ProjectRow.tsx` |
| 里程碑 | F1（外壳、项目栏、文件栏） |
| 规格状态 | 草案 v0.1，2026-11-22，待用户确认 |

项目树中的一行：文件夹图标、项目名、对话数。点击展开/收起其对话列表并切换当前项目。

## 上一级：从哪里进来

| 入口 | 触发条件 | 传入的数据 / 接口 |
|---|---|---|
| 项目栏 | 每个项目一行 | props `project: Project`, `expanded: boolean` |

## 下一级：去哪里

| 操作 | 结果 | 目标规格 | 调用的接口 / store action |
|---|---|---|---|
| 点击 | 设为当前项目并展开；已展开则收起 | — | `useChat.setProject(id)`；文件栏随之刷新 |
| 展开后渲染对话行 | — | [1-项目行-对话行](1-项目行-对话行.md) | query `['conversations', pid]` |
| 展开后末尾“加载更多” | — | [1-项目行-加载更多](1-项目行-加载更多.md) | — |

## 接口

| 类型 | 名称 | 何时调用 | 字段与说明 |
|---|---|---|---|
| query | `['conversations', pid]` | 展开时 | 首页 3 条（概念图），点加载更多翻页 |

字段定义见 [REST](../../../contract/rest-api.md)、[SSE](../../../contract/sse-events.md)、[类型](../../../contract/types.ts)；query key 见 [state.md](../../../ux/state.md)。

## 读写的前端状态

- useChat.projectId
- 本地 state `expandedIds`（持久化到 `mn.sidebar.v1`）

## 状态

| 状态 | 表现 |
|---|---|
| 当前项目 | 打开的文件夹图标 |
| 其他项目 | 关闭的文件夹图标，对话数为灰色 |
| 展开中加载 | 对话区 2 行骨架 |

## 交互细则

- 切换项目不自动打开对话；中间区保持当前视图，若当前对话不属于新项目则回到主页。
