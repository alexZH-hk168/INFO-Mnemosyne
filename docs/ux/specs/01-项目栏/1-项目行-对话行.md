# 1-项目行-对话行

| 项 | 值 |
|---|---|
| ID / data-testid | `sidebar.conversation-row` |
| 类型 | 按钮 |
| 级数 | 1 |
| 上级规格 | [1-项目栏-项目行](1-项目栏-项目行.md) |
| 概念图 | [UI-05](../../../assets/ui/05-workspace-branch.png) |
| 建议组件 | `web/src/project/ConversationRow.tsx` |
| 里程碑 | F1（外壳、项目栏、文件栏） |
| 规格状态 | 草案 v0.1，2026-11-22，待用户确认 |

对话列表中的一行：气泡图标、标题（省略号）、分支数（分支图标＋数字）或最近时间。

## 上一级：从哪里进来

| 入口 | 触发条件 | 传入的数据 / 接口 |
|---|---|---|
| 项目行展开 | 每个对话一行 | props `conversation: ConversationSummary`, `active: boolean` |

## 下一级：去哪里

| 操作 | 结果 | 目标规格 | 调用的接口 / store action |
|---|---|---|---|
| 点击 | 打开该对话主线 | [1-对话行-对话栏](../05-对话栏/1-对话行-对话栏.md) | `useChat.setConversation(cid)`、`useLayout.view="conversation"`、路由 `/c/:cid` |
| 点击分支数 | 同上，并在右栏打开最近一个 open 分支 | [2-开分支追问-分支面板](../06-右栏/2-开分支追问-分支面板.md) | `useLayout.openTab({kind:"branch"})` |

## 接口

不直接调用后端接口。

## 读写的前端状态

- useChat.conversationId

## 状态

| 状态 | 表现 |
|---|---|
| 当前对话 | `--sel` 底色 |
| branch_count > 0 | 显示分支图标与数字 |
| branch_count = 0 | 显示相对时间（昨天 / 3 天前） |

## 交互细则

- 标题由后端首轮回答后生成；未生成前显示首条用户消息前 20 字。

## 验收

- [ ] 点击后对话栏显示该对话，URL 为 `/c/:cid`。
- [ ] 所有可点元素带 `data-testid`，键盘可达，焦点可见。
