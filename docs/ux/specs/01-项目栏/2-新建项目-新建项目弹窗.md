# 2-新建项目-新建项目弹窗

| 项 | 值 |
|---|---|
| ID / data-testid | `sidebar.new-project-dialog` |
| 类型 | 弹窗 |
| 级数 | 2 |
| 上级规格 | [1-项目栏-新建项目按钮](1-项目栏-新建项目按钮.md) |
| 概念图 | 无（实现前需补概念图或实现后截图确认） |
| 建议组件 | `web/src/project/NewProjectDialog.tsx` |
| 里程碑 | F1（外壳、项目栏、文件栏） |
| 规格状态 | 草案 v0.1，2026-11-22，待用户确认 |

居中小弹窗：一个名称输入框（1–60 字）＋取消/创建。

## 上一级：从哪里进来

| 入口 | 触发条件 | 传入的数据 / 接口 |
|---|---|---|
| 新建项目按钮 | `useUI.modal.kind === "new-project"` | — |

## 下一级：去哪里

| 操作 | 结果 | 目标规格 | 调用的接口 / store action |
|---|---|---|---|
| 创建 / 回车 | 建项目，关闭弹窗，项目栏选中新项目并进入其主页 | [1-新建对话-主页](../03-主页/1-新建对话-主页.md) | POST /api/projects；成功后失效 `['projects']`、`useChat.setProject(id)` |
| 取消 / Esc / 点遮罩 | 关闭 | — | `useUI.closeModal()` |

## 接口

| 类型 | 名称 | 何时调用 | 字段与说明 |
|---|---|---|---|
| REST | `POST /api/projects` | 提交 | `{name}` → `Project`；`VALIDATION_ERROR` 显示在输入框下 |

字段定义见 [REST](../../../contract/rest-api.md)、[SSE](../../../contract/sse-events.md)、[类型](../../../contract/types.ts)；query key 见 [state.md](../../../ux/state.md)。

## 读写的前端状态

- useUI.modal
- useChat.projectId

## 状态

| 状态 | 表现 |
|---|---|
| 空名称 | 创建按钮置灰 |
| 提交中 | 按钮显示加载，输入框只读 |
| 失败 | 输入框下红字错误，保留输入 |

## 交互细则

- 名称前后空格去掉后再提交。

## 验收

- [ ] 新项目出现在项目树顶部并展开。
- [ ] 所有可点元素带 `data-testid`，键盘可达，焦点可见。

## 待确认 / 缺口
