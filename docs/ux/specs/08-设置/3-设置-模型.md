## 状态

| 状态 | 表现 |
|---|---|
| 已配置（llm_mode=real） | 横幅：“正在使用你自己的模型 <对话模型>。调用费用由你的密钥承担，Mnemosyne 不内置任何付费模型。” |
| 未配置（llm_mode=demo） | 横幅：“演示模式：还没有配置模型，回答由本地示例生成。填好 API 地址、API Key 和对话模型并保存后，自动改用你自己的模型。”Key 区直接是 password 输入框，“测试连接”禁用 |
| 服务端强制演示（demo_forced） | 横幅说明服务端只用本地示例回答（测试用），这里的配置暂不生效 |
| Key 已设置 | 显示“已设置 ••••abcd 修改 清除”（掩码来自 `api_key_hint`，密钥短于 12 位时只显示“已设置”） |
| 测试中 | 按钮内转圈，禁止重复点击 |
| 测试成功 | 浅色结果框：“连接成功：…”＋“支持工具调用 · 未填嵌入模型 · 412 ms” |
| 测试失败 | 红色结果框，`message` 原样显示（密钥无效 / 余额不足 / 限流 / 模型不存在 / 不支持工具调用 / 地址不通 / 超时） |
| 服务商没有嵌入接口（DeepSeek） | 嵌入模型占位“该服务商没有嵌入接口”，说明行补“嵌入模型留空即可”；检索仍用本地 BM25 + 本地向量 |

## 交互细则

- 密钥输入框 `type="password"`、`autocomplete="new-password"`；任何接口都不回传明文，界面只显示末 4 位掩码。
- 预设的地址、模型名、工具调用与嵌入支持都来自后端（官方文档核对，链接在预设的 `doc_urls`），前端不硬编码。
- “测试连接”不保存设置；保存也不强制先测试。
- 说明行写清：对话模型需要支持工具调用；小模型用于起标题、整理历史对话；当前检索方式（`retrieval_mode`）。

## 验收

- [ ] 选 DeepSeek 后 API 地址、对话模型、小模型自动填好，嵌入模型为空；保存请求带 `provider:"deepseek"`。
- [ ] 测试连接请求不含已存 Key；密钥无效时显示“密钥无效”。
- [ ] 清除 Key 并保存后横幅变为演示模式，输入框下出现演示模式提示。
- [ ] 后端测试：接口响应、SSE、日志、数据库事件里都搜不到密钥原文。
- [ ] 所有可点元素带 `data-testid`，键盘可达，焦点可见。
