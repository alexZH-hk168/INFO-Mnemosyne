## 上一级：从哪里进来

| 入口 | 触发条件 | 传入的数据 / 接口 |
|---|---|---|
| 用户卡片 | `useUI.modal.kind==="settings"` | — |
| 输入框演示模式提示“去设置” | `openModal("settings", {section:"model"})` | — |

## 下一级：去哪里

| 操作 | 结果 | 目标规格 | 调用的接口 / store action |
|---|---|---|---|
| 导航“模型” | 右侧切到模型页 | [3-设置-模型](3-设置-模型.md) | 本地 state `section` |
| 导航“记忆” | 右侧切到记忆管理 | [3-设置-记忆管理](3-设置-记忆管理.md) | 本地 state `section` |
| 保存 | 保存当前页 | — | PUT /api/settings |
| 关闭 / Esc | 关闭 | — | `useUI.closeModal()` |

## 接口

| 类型 | 名称 | 何时调用 | 字段与说明 |
|---|---|---|---|
| query | `['settings']` | 打开 | — |
| REST | `PUT /api/settings` | 保存 | API Key 只写；成功后失效 `['settings']` |

字段定义见 [REST](../../../contract/rest-api.md)、[SSE](../../../contract/sse-events.md)、[类型](../../../contract/types.ts)；query key 见 [state.md](../../../ux/state.md)。

## 交互细则

- 记忆开关放在记忆页，不放首页或输入框。
- `modal.props.section` 可指定打开哪一页（model / search / memory），缺省为模型页。
