# 3-设置-记忆管理

| 项 | 值 |
|---|---|
| ID / data-testid | `settings.memory` |
| 类型 | 窗口 |
| 级数 | 3 |
| 上级规格 | [2-用户卡片-设置弹窗](2-用户卡片-设置弹窗.md) |
| 概念图 | 无（实现前需补概念图或实现后截图确认） |

| 里程碑 | F6（市场、插件、设置） |

设置弹窗里的“记忆”页：记忆开关、画像摘要（只读）、按作用域与主题筛选的记忆条目列表，每条可编辑、删除、查看来源消息。

| 入口 | 触发条件 | 传入的数据 / 接口 |
|---|---|---|
| 设置弹窗导航“记忆” | — | — |

## 下一级：去哪里

| 操作 | 结果 | 目标规格 | 调用的接口 / store action |
|---|---|---|---|
| 编辑条目 | 行内编辑后保存 | — | PUT /api/memory/items/{id} |
| 删除条目 | 二次确认后删除，条目进屏蔽列表 | — | DELETE /api/memory/items/{id} |
| 查看来源 | 关闭设置，打开来源对话并在右栏显示原消息 | [2-证据胶囊-历史对话预览](../06-右栏/2-证据胶囊-历史对话预览.md) | `useLayout.openTab({kind:"message"})` |
| 记忆开关 | 关闭后不再抽取新记忆，已有记忆保留 | — | PUT /api/settings `{memory_enabled}` |

## 接口

| 类型 | 名称 | 何时调用 | 字段与说明 |
|---|---|---|---|
| query | `['memory', filters]` | 打开与筛选 | GET /api/memory/items |
| query | `['memorySummary']` | 打开 | GET /api/memory/summary |

字段定义见 [REST](../../../contract/rest-api.md)、[SSE](../../../contract/sse-events.md)、[类型](../../../contract/types.ts)；query key 见 [state.md](../../../ux/state.md)。

## 读写的前端状态

- 无全局状态，只用组件内部 state。

## 状态

| 状态 | 表现 |
|---|---|
| 无条目 | “还没有记忆。多聊几轮后这里会出现你学过的主题和易错点。” |
| superseded 条目 | 默认隐藏，勾选“显示历史版本”后以删除线显示并带有效期 |

## 交互细则

- 删除确认文案说明边界：“删除后助手不再使用这条记忆，原始对话仍保留。”

## 验收

- [ ] 删除后刷新不再出现；对应原话再次出现时不会被重新抽取（后端测试覆盖）。
- [ ] 所有可点元素带 `data-testid`，键盘可达，焦点可见。
