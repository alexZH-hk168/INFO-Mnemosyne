字段定义见 [REST](../../../contract/rest-api.md)、[SSE](../../../contract/sse-events.md)、[类型](../../../contract/types.ts)；query key 见 [state.md](../../../ux/state.md)。

## 读写的前端状态

- useChat.streaming.steps

## 状态

| 状态 | 表现 |
|---|---|
| running | 摘要文字后加转圈，显示当前步骤 label |
| 含 error 步骤 | 该步红色，摘要末尾“1 步失败” |
| 无步骤 | 不渲染 |

## 交互细则

- 摘要由前端统计：search_materials 去重文档数、search_web/fetch_url 网页数、recall_memory/open_source 计为“历史对话”。
- 记忆相关步骤只说“参考 N 段历史对话”，不出现“记忆”字样（用户要求不强调记忆）。
