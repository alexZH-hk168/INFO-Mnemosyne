## 上一级：从哪里进来

| 入口 | 触发条件 | 传入的数据 / 接口 |
|---|---|---|
| 对话栏头部 | 渲染 | 读 `tree.branches` |

| 操作 | 结果 | 目标规格 | 调用的接口 / store action |

| 点击 | 弹出分支列表（标题、锚点原句前 20 字、状态） | — | 本地 popover |
| 点列表中某个分支 | 右栏打开该分支 | [2-开分支追问-分支面板](../06-右栏/2-开分支追问-分支面板.md) | `useLayout.openTab({kind:"branch", ref_id: bid})` |

## 接口

不直接调用后端接口。

## 读写的前端状态

- useLayout.rightTabs

## 状态

| 状态 | 表现 |
|---|---|
| 0 个分支 | 只显示“主线”，不可点 |
| 有 merged/archived | 列表里灰色，标“已合并”/“已归档” |
