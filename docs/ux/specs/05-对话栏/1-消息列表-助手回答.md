## 读写的前端状态

- useChat.streaming（当前那条）

## 状态

| 状态 | 表现 |
|---|---|
| streaming | 正文逐字出现，胶囊为虚线待确认 |
| verifying | 正文完整，胶囊仍为虚线，步骤行末尾“核对引用…” |
| saved | 胶囊按 verdict 显示 |
| cancelled | 末尾灰字“已停止生成” |
| error | 红色提示条＋“重新生成” |

## 交互细则

- 正文按“去掉 `[[E#]]` 后的纯文本”计算句子与锚点偏移（与契约一致）。
- Markdown 用 react-markdown + remark-math + rehype-katex；胶囊用自定义 remark 插件把 `[[E#]]` 换成组件。
