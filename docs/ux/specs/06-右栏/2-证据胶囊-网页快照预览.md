# 2-证据胶囊-网页快照预览

| 项 | 值 |
|---|---|
| ID / data-testid | `right.web-preview` |
| 类型 | 窗口 |
| 级数 | 2 |
| 上级规格 | [1-外壳-右栏](1-外壳-右栏.md) |
| 概念图 | 无（实现前需补概念图或实现后截图确认） |
| 建议组件 | `web/src/preview/WebSnapshotViewer.tsx` |
| 里程碑 | F4（右栏预览） |
| 规格状态 | 草案 v0.1，2026-11-22，待用户确认 |

显示抓取时保存的网页正文快照（纯文本排版，不加载原网页）。顶部原 URL、抓取时间、“打开原网页”。

## 上一级：从哪里进来

| 入口 | 触发条件 | 传入的数据 / 接口 |
|---|---|---|
| 证据胶囊（网页） / 网页来源行 | tab kind=web | `ref_id=snapshot_id`, `locator.char_range` |

其他指向本规格的规格：[1-文件分组-网页来源行](../02-文件栏/1-文件分组-网页来源行.md)、[1-助手回答-证据胶囊](../05-对话栏/1-助手回答-证据胶囊.md)。

## 下一级：去哪里

| 操作 | 结果 | 目标规格 | 调用的接口 / store action |
|---|---|---|---|
| 打开原网页 | 新窗口打开原 URL | — | `window.open(url, "_blank", "noopener")` |

## 接口

| 类型 | 名称 | 何时调用 | 字段与说明 |
|---|---|---|---|
| query | `['snapshot', sid]` | 打开 | GET /api/web_snapshots/{sid} |

字段定义见 [REST](../../../contract/rest-api.md)、[SSE](../../../contract/sse-events.md)、[类型](../../../contract/types.ts)；query key 见 [state.md](../../../ux/state.md)。

## 读写的前端状态

- 无全局状态，只用组件内部 state。

## 状态

| 状态 | 表现 |
|---|---|
| 有 char_range | 高亮并滚到该段 |
| NOT_VISIBLE_ON_PATH | “这个网页不在当前分支的可见范围内” |

## 交互细则

- 快照用纯文本渲染，不用 iframe 加载原站（避免脚本与追踪）。

## 验收

- [ ] 高亮段落与 quote 一致。
- [ ] 所有可点元素带 `data-testid`，键盘可达，焦点可见。
