# 2-证据胶囊-历史对话预览

| 项 | 值 |
|---|---|
| ID / data-testid | `right.message-preview` |
| 类型 | 窗口 |
| 级数 | 2 |
| 上级规格 | [1-外壳-右栏](1-外壳-右栏.md) |
| 概念图 | 无（实现前需补概念图或实现后截图确认） |
| 建议组件 | `web/src/preview/MessageViewer.tsx` |
| 里程碑 | F4（右栏预览） |
| 规格状态 | 草案 v0.1，2026-11-22，待用户确认 |

灰色胶囊（历史对话）打开后显示那段原始对话（只读），高亮被引用的字符区间，顶部“来自对话：<标题> · 日期”，可“打开该对话”。

## 上一级：从哪里进来

| 入口 | 触发条件 | 传入的数据 / 接口 |
|---|---|---|
| 证据胶囊（历史对话） / 设置·记忆 的“查看来源” | tab kind=message | `ref_id=message_id`, `char_range` |

其他指向本规格的规格：[3-设置-记忆管理](../08-设置/3-设置-记忆管理.md)、[1-助手回答-证据胶囊](../05-对话栏/1-助手回答-证据胶囊.md)。

## 下一级：去哪里

| 操作 | 结果 | 目标规格 | 调用的接口 / store action |
|---|---|---|---|
| 打开该对话 | 切换中间区到该对话并滚到消息 | [1-对话行-对话栏](../05-对话栏/1-对话行-对话栏.md) | `useChat.setConversation` |

## 接口

| 类型 | 名称 | 何时调用 | 字段与说明 |
|---|---|---|---|
| query | `['evidence', eid]` | 打开 | `context_messages`：被引消息前后各 1 条 |

字段定义见 [REST](../../../contract/rest-api.md)、[SSE](../../../contract/sse-events.md)、[类型](../../../contract/types.ts)；query key 见 [state.md](../../../ux/state.md)。
