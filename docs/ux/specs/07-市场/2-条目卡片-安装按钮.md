# 2-条目卡片-安装按钮

| 项 | 值 |
|---|---|
| ID / data-testid | `market.install-button` |
| 类型 | 按钮 |
| 级数 | 2 |
| 上级规格 | [2-市场页-条目卡片](2-市场页-条目卡片.md) |
| 概念图 | [UI-07](../../../assets/ui/07-market-plugins.png)、[UI-09](../../../assets/ui/09-plugin-detail.png) |
| 建议组件 | `web/src/market/InstallButton.tsx` |
| 里程碑 | F6（市场、插件、设置） |
| 规格状态 | 草案 v0.1，2026-11-22，待用户确认 |

卡片和详情页右上共用的安装按钮。插件打开安装确认弹窗；Skill 直接导入。

## 上一级：从哪里进来

| 入口 | 触发条件 | 传入的数据 / 接口 |
|---|---|---|
| 条目卡片 / 插件详情 / Skill 详情 | 渲染 | props `item` |

其他指向本规格的规格：[3-条目卡片-插件详情页](3-条目卡片-插件详情页.md)、[3-条目卡片-Skill详情页](3-条目卡片-Skill详情页.md)。

## 下一级：去哪里

| 操作 | 结果 | 目标规格 | 调用的接口 / store action |
|---|---|---|---|
| 插件：点击 | 打开安装确认弹窗 | [3-安装-安装确认弹窗](3-安装-安装确认弹窗.md) | `useUI.openModal("install", {pluginId})` |
| Skill：点击 | 导入并启用 | — | POST /api/skills/import `{source:"github", url: repo_url}`；失效 `['skills']`、`['market','skills']` |
| 已安装：点击 | 进入详情 | [3-条目卡片-插件详情页](3-条目卡片-插件详情页.md)、[3-条目卡片-Skill详情页](3-条目卡片-Skill详情页.md) | — |

## 接口

| 类型 | 名称 | 何时调用 | 字段与说明 |
|---|---|---|---|
| REST | `POST /api/skills/import` | Skill 安装 | 失败 `SKILL_INVALID` 时提示原因 |

字段定义见 [REST](../../../contract/rest-api.md)、[SSE](../../../contract/sse-events.md)、[类型](../../../contract/types.ts)；query key 见 [state.md](../../../ux/state.md)。

## 读写的前端状态

- useUI.modal

## 状态

| 状态 | 表现 |
|---|---|
| 安装中 | 转圈 |
| 已安装 | “已安装 · 本对话已启用”（在对话上下文中）或“已安装 ✓” |
