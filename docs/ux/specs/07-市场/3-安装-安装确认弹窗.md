# 3-安装-安装确认弹窗

| 项 | 值 |
|---|---|
| ID / data-testid | `market.install-dialog` |
| 类型 | 弹窗 |
| 级数 | 3 |
| 上级规格 | [2-条目卡片-安装按钮](2-条目卡片-安装按钮.md) |
| 概念图 | 无（实现前需补概念图或实现后截图确认） |
| 建议组件 | `web/src/market/InstallDialog.tsx` |
| 里程碑 | F6（市场、插件、设置） |
| 规格状态 | 草案 v0.1，2026-11-22，待用户确认 |

插件安装三步：① 权限确认（逐项列出 manifest 声明的权限，注明“插件自行声明，v1 不做沙箱”）② 填配置（env_schema 字段，密钥用密码框）③ 安装并自检（启动＋tools/list）。

## 上一级：从哪里进来

| 入口 | 触发条件 | 传入的数据 / 接口 |
|---|---|---|
| 安装按钮 | `useUI.modal.kind==="install"` | `pluginId` → manifest |

## 下一级：去哪里

| 操作 | 结果 | 目标规格 | 调用的接口 / store action |
|---|---|---|---|
| 下一步 / 安装 | 提交配置，后端启动并自检 | — | POST /api/plugins/{id} `{config}` |
| 成功 | 关闭弹窗，详情页按钮变“已安装 · 本对话已启用”，当前对话自动启用 | [3-条目卡片-插件详情页](3-条目卡片-插件详情页.md) | 失效 `['plugins']`、`['plugin', id]`、`['convPlugins', cid]`；PUT /api/conversations/{cid}/plugins |
| 失败“查看日志” | 展开 `log_tail` | — | 本地 state |
| 取消 / Esc | 关闭 | — | `useUI.closeModal()` |

## 接口

| 类型 | 名称 | 何时调用 | 字段与说明 |
|---|---|---|---|
| REST | `POST /api/plugins/{id}` | 安装 | `PLUGIN_SELF_CHECK_FAILED` 带 `log_tail` |
| REST | `PUT /api/conversations/{cid}/plugins` | 成功且有当前对话 | 追加该插件 |

字段定义见 [REST](../../../contract/rest-api.md)、[SSE](../../../contract/sse-events.md)、[类型](../../../contract/types.ts)；query key 见 [state.md](../../../ux/state.md)。

## 状态

| 状态 | 表现 |
|---|---|
| 自检中 | “正在启动并检查工具…”，约 5–30 s |

| 无需配置 | 跳过第 ② 步 |
